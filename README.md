# Story Atelier · 剧情记忆馆

一个面向 SillyTavern / TauriTavern 的独立剧情记忆扩展：按聊天保存人物、世界设定与剧情时间线，可手动或自动总结，并在后续生成时注入相关记忆。

> **来源与使用说明**：本项目的剧情记忆核心衍生自 S.A. · DW2 的 Story Memory 模块。原始来源未附明确开源许可证，因此保留来源说明；本仓库的存在不代表取得原始代码的再发布或再授权。请勿将本项目或其衍生代码对外分发，除非已取得相关权利人的明确许可。

## 功能

- 每个角色卡 / 聊天分别维护剧情记忆。
- 人物、世界设定、剧情时间线分组保存、编辑和导出。
- 手动总结、自动总结、下轮上下文注入。
- 可选语义召回；网络或接口不支持时可关闭。
- 楼层隐藏 / 恢复：按楼层编号或范围执行 TT 原生 `/hide`、`/unhide` 指令。

## 安装

1. 将本仓库中的 `index.js`、`style.css`、`manifest.json` 放入扩展目录。
2. 在 TT 酒馆的扩展管理中加载该扩展，或按你当前安装方式将仓库作为扩展来源。
3. 打开扩展菜单中的「剧情记忆馆」进入设置。

## 初次设置

1. 填写兼容 OpenAI API 的接口地址、API Key 与模型 ID。
2. 点击「保存设置」。
3. 按需开启「启用剧情记忆」「自动总结」「注入下轮聊天」。
4. 可先点「拉取当前剧情（总结一批）」测试，再开启自动总结。

## 楼层操作

在剧情记忆馆面板中输入单层编号（如 `12`）或范围（如 `12-18`），点击「隐藏楼层」或「恢复楼层」。楼层编号以 TT 当前聊天的数组索引为准；操作后请在聊天中确认效果。

**注意：隐藏楼层不等于删除聊天正文。** 它调用 TT 原生楼层指令，具体显示与上下文行为以当前 TT 版本为准。若某版本不支持这些原生命令，面板会提示失败或无接口。

## 隐私与安全

- 剧情文本会发送到你配置的第三方 API 进行总结 / 召回，请只使用你信任的服务。
- 默认不在浏览器本地持久保存 API Key；勾选「在此设备保存 API Key」后会以明文存入本地存储，存在风险。
- 剧情记忆存储在当前浏览器 / WebView 的 localStorage 中。清理站点数据可能导致记忆丢失，请定期导出备份。
- 不会主动删除聊天消息正文。

## 兼容性

使用 SillyTavern 的 `SillyTavern.getContext()` 与生成拦截器接口。实际安卓 / iOS 设备、不同 TT 2.3.x 构建及各类第三方 API 的兼容性仍需在目标环境中实测。
